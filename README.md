# book_reading

这是一个用于整理和总结读书笔记的仓库。每本书一个文件夹，里面放各版本笔记。

## 页面

发布地址：<https://ghsshou.github.io/book_reading/>

页面由各书文件夹里的 `读书笔记.md` 生成。合并到 `main` 后，GitHub Actions 会重新构建并部署。
