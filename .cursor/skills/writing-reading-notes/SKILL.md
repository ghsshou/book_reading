# 读书笔记（读后感）

把摘抄和个人想法写成一篇带感受的读后感，不是书摘提纲。

## 输出是什么

一篇顺着阅读走下来的文章：有书里的场景和判断，也有读者自己的看法。读者读完应感到「这人读过、想过」，而不是「这是目录扩写」。

**不是：** 按章节罗列「要点 / 摘抄 / 想法」；把书中观点凝练成条目；给每章贴标签。

## 工作流程

1. **收原料。** 用户贴的摘抄全部保留实质，去重即可。感叹词可忽略：嗯、确实、神奇、是啊、哇、确实哦。有内容的想法必须写进正文，不要单独挂成「想法：」列表。
2. **补全书脉络（需要时）。** 可联网查全书结构，用来把摘抄接上，不拿二手书评替换用户原文。
3. **先写 Markdown 读后感。** 按阅读感受推进，可用主题小标题（如「自由会不会成为负担」），不要用「第一章」「第二章」。
4. **再出无格式版。** 同一篇文章，去掉标题符号、加粗、引用块、表格、链接；写成连贯散文，不要按章节切块。供粘贴到书评/评论。
5. **落盘并更新索引。**

## 文风

- 用「读到……会觉得……」把书和人接上，不要先抛概念再解释。
- 书中关键原句可直接引入，但要用自己的话接住。
- 个人判断嵌在叙述里，例如「所说的和真实动机并不一致」「心理历程无法跳跃」。
- 口吻平实、完整句子。不要清单腔，不要「本章在全书中的位置」。
- 结尾收在读完还留下什么，不要再做一次全书摘要。

## 文件与命名

中文文件名，格式为 `书名 读书笔记` 或 `书名 读书笔记-xx 版`。

| 文件 | 路径 |
|------|------|
| 摘抄原文（只整理、不改意见） | `raw/<作者或主题>/书名 读书笔记-摘抄原文.md` |
| Markdown 读后感 | `wiki/<作者或主题>/书名 读书笔记.md` |
| 无格式版 | `wiki/<作者或主题>/书名 读书笔记-无格式版.txt` |

主题目录沿用已有子目录；没有则用作者姓氏或领域短名（如 `fromm`）。

Markdown 文首：

```markdown
# 《书名》读书笔记

> Sources: 作者，《书名》，出版年；译本信息；阅读摘抄与想法 YYYY-MM 至 YYYY-MM
> Raw: [摘抄原文](../../raw/<topic>/书名%20读书笔记-摘抄原文.md)
```

然后是 `## Overview`（一段说明这是读后感）和若干主题小节。

落盘后更新：

- `wiki/index.md` — 一行：链接、一句话摘要、日期
- `wiki/log.md` — 追加 `## [YYYY-MM-DD] ingest | 书名 读书笔记`
- `README.md` — 笔记列表加上新书

本仓库文件命名以本 skill 为准，不要改用英文 kebab-case。

## 无格式版

从读后感抽出正文，做成一篇可粘贴的散文：

- 去掉 `#`、`**`、`>`、表格、链接、YAML
- 不用「第一章」或目录式小标题；段落之间靠句子转下去
- 不要出现「整章的压轴」「附录把方法收束」这类章节导游句

用户若只要评论版，只给无格式版，并说明字数。

## 反例 / 正例

反例（不要这样）：

```
## 第三章 宗教改革时代的自由
### 要点
- 路德的臣服被说成爱
### 想法
- 2026/07/15：所说的和真实动机并不一致
```

正例（要这样）：

```
路德说自己对上帝的臣服是自愿的，出于爱而非恐惧。从心理结构看，这种爱就是臣服。
读到这里会立刻想起：所说的和真实动机，本来就不一致。
```

## 常见错误

| 借口 | 实际 |
|------|------|
| 「按章节写才不会漏」 | 漏不漏靠是否吃进摘抄，不靠目录骨架 |
| 「先总结再写感受」 | 感受要写进叙述，不要附录化 |
| 「无格式版就是去 Markdown」 | 还要把章节块打成一篇文章 |
| 「感叹也算想法」 | 嗯、确实、神奇丢掉；有判断的句子留下 |

- [ ] 不是章节提纲
- [ ] 用户的实质摘抄都在（可改写嵌入，不可丢掉）
- [ ] 有内容的个人想法已写进正文
- [ ] Markdown 版 + 无格式版都有
- [ ] 文件名为 `书名 读书笔记` / `书名 读书笔记-无格式版` / `书名 读书笔记-摘抄原文`
- [ ] index、log、README 已更新
